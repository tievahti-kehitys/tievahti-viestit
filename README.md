# tievahti-viestit

Tievahdin julkiset viestintäsivut: uutiskirjeen peruutussivu
(`peruuta.html`) ja sisällöntuottajan kirjepaja (`index.html`).

Sivut eivät sisällä salaisuuksia; ne kutsuvat Tievahdin omaa API:a Supabasessa.
**Lähdekoodin koti on privaatti repo `tievahti-marketing-core` (`ui/`)** —
älä muokkaa tätä repoa käsin, vaan aja siellä `node scripts/ui/deploy-pages.mjs`.
